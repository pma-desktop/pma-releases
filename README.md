# PMA — Personal Media Archive

PMA — личный кинодневник для Windows. В нём можно вести историю просмотров, сохранять впечатления и собирать очередь фильмов. Когда в коллекции набирается достаточно оценок, PMA предлагает фильмы, которые могут вам понравиться.

**[Скачать PMA для Windows x64](https://github.com/pma-desktop/pma-releases/releases/latest)** · [Все выпуски](https://github.com/pma-desktop/pma-releases/releases) · [Как работают рекомендации](RECOMMENDATIONS.md)

## Что можно делать в PMA

- **Вести историю просмотров.** Записывайте дату, впечатления и оценки по своим критериям. Для пересмотра можно сохранить отдельную запись и вернуться к предыдущим впечатлениям.
- **Планировать просмотры.** Добавляйте фильмы в «Хочу посмотреть» и расставляйте их в нужном порядке. После просмотра сохраните оценку и заметку в дневнике.
- **Находить новые фильмы.** Начиная с версии 0.8.0, PMA составляет подборку по вашим оценкам и объясняет, какие фильмы из коллекции повлияли на выбор. Рекомендацию можно добавить в очередь прямо из карусели.
- **Смотреть статистику.** В статистике собраны просмотры, пересмотры, любимые фильмы и жанры. Отдельная вкладка показывает, сколько рекомендаций дошло до просмотра и какую оценку они получили.

## Установка

Выберите подходящий файл в разделе **Assets** последнего выпуска.

- **`PMA-Setup.exe`** устанавливает приложение и добавляет ярлык в меню «Пуск».
- **`PMA.exe`** запускает приложение без установки.
- **`PMA-<версия>.films-update`** обновляет установленное приложение через «Настройки → Обновления → Из файла».

Для обычного обновления откройте **Настройки → Обновления → Проверить обновления**. PMA проверит подпись пакета и перед установкой сохранит резервную копию коллекции и черновиков.

**Переход с 0.7.0 или более ранней версии.** Сначала установите [PMA 0.7.1](https://github.com/pma-desktop/pma-releases/releases/tag/v0.7.1). В ней увеличен лимит размера пакета. После перезапуска снова проверьте обновления, чтобы перейти на 0.8.0.

## Хранение коллекции

Коллекция, оценки и впечатления хранятся на вашем компьютере. Для работы с дневником учётная запись не нужна. В настройках данных можно экспортировать коллекцию в JSON, сохранить резервную копию или восстановить коллекцию из файла.
